# 功能 → 模式对照表

> 这一页按“功能诉求”来找模式。  
> 比起先问“这是哪一种模式”，更像是在问“我现在想实现什么能力”。

---

## 一、功能总表

| 唯一资源管理（总线、全局调度、缓存中心） | 单例 | 代理、生成器 | 基础设施层 | [模式总表](./pattern_index.md) |
| 新旧接口兼容 | 适配器 | 外观、桥接 | 驱动抽象层 | [C05](./combos.md#c05) |
| 统一子系统入口 | 外观 | 适配器、代理、装饰 | 服务层 | [C05](./combos.md#c05) |
| 抽象与实现分离 | 桥接 | 工厂方法、策略 | 驱动抽象层 | [C08](./combos.md#c08) |

| 缓存 / 延迟加载 / 权限控制 | 代理 | 装饰、单例 | 驱动抽象层 / 资源层 | [C07](./combos.md#c07) |
| 降低 RAM 占用 / 共享对象 | 享元 | 原型、单例、代理 | 基础设施层 | [C07](./combos.md#c07) |

| 一对多事件通知 | 观察者 | 中介者、状态、命令 | 业务层 / 服务层 | [C03](./combos.md#c03) |
| 多模块复杂协作 | 中介者 | 观察者、命令、状态 | 服务层 | [C03](./combos.md#c03) |
| 命令队列 / 请求对象化 / 解耦触发与执行 | 命令 | 状态、责任链、中介者 | 业务层 / 服务层 | [C03](./combos.md#c03) |
| 算法 / 处理逻辑可替换 | 策略 | 状态、模板方法 | 业务层 / 服务层 | [C03](./combos.md#c03) |

| 分级校验 / 过滤 / 逐段处理 | 责任链 | 解释器、命令、状态 | 协议层 / 服务层 | [C04](./combos.md#c04) |
| 保存现场 / 参数回滚 / 快照恢复 | 备忘录 | 原型、观察者、组合 | 配置层 / 资源层 | [C06](./combos.md#c06) |
| 默认配置复制 / 模板实例生成 | 原型 | 生成器、备忘录、享元 | 配置层 / 资源层 | [C02](./combos.md#c02) |
| 平台对象族整体装配 | 抽象工厂 | 工厂方法、桥接 | 服务层 | [C01](./combos.md#c01) |

## 二、按“工程目标”汇总

| 工程目标 | 优先看 |
|---|---|
| 减耦 | 桥接、适配器、外观、中介者 |
| 扩展性 | 策略、装饰、模板方法、访问者 |
| 资源控制 | 单例、代理、享元 |
| 可移植性 | 抽象工厂、工厂方法、桥接、适配器 |
| 可维护性 | 状态、命令、责任链、外观 |
| 配置与恢复能力 | 生成器、原型、备忘录 |
| 数据结构抽象 | 组合、迭代器、访问者 |
| 协议 / 规则处理 | 解释器、责任链、状态 |

## 三、按“你最可能说出口的话”查找

| 你可能会说 | 更可能对应 |
|---|---|
| “我想让业务层不关心底层驱动差异” | 桥接、抽象工厂、适配器 |
| “我想把一大坨初始化拆成几步” | 生成器、模板方法 |
| “我想给现有驱动包一层日志和缓存” | 装饰、代理 |
| “我想做一个显式状态机” | 状态 |
| “我想让事件变化自动通知多个模块” | 观察者 |
| “我想让多个模块别直接互相调来调去” | 中介者 |
| “我想把解析和校验拆成好几段” | 解释器、责任链 |
| “我想节省 RAM，很多对象其实差不多” | 享元、原型 |
| “我想保存一份配置，失败了再回滚” | 备忘录 |
| “我想在树形配置上批量导出 / 检查 / 统计” | 组合、迭代器、访问者 |
