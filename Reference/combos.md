## C01 多平台驱动族组合

### 组合
- 抽象工厂
- 工厂方法
- 桥接
- 适配器

### 适合场景
- 同一套业务代码适配不同 MCU / 板卡
- 同一类设备有多套底层实现
- 旧驱动接口和新抽象接口并存

### 组合关系
- **抽象工厂**：负责整套对象族装配
- **工厂方法**：把具体实现选择下放
- **桥接**：把抽象接口与底层实现解耦
- **适配器**：兼容旧驱动或三方接口

## C02 复杂初始化组合

### 组合
- 生成器
- 模板方法
- 单例
- 原型

### 适合场景
- 初始化步骤多且顺序严格
- 参数对象需要分步骤填充
- 系统中存在唯一控制器
- 需要基于默认配置快速复制实例

### 组合关系
- **生成器**：负责“怎么一步步组起来”
- **模板方法**：固定大流程骨架
- **单例**：控制唯一资源
- **原型**：复制模板配置，避免重复构建

## C03 状态机事件流组合

### 组合
- 状态
- 观察者
- 中介者
- 命令
- 策略

### 适合场景
- 设备生命周期复杂
- 模块间靠事件驱动协作
- 同一状态下可能有不同处理策略
- 动作需要对象化、排队或延迟执行

### 组合关系
- **状态**：表示当前处于什么阶段
- **观察者**：状态变化后通知相关模块
- **中介者**：减少模块之间直接耦合
- **命令**：把动作封装成消息 / 请求
- **策略**：在不同模式下替换处理算法

## C04 协议解析流水线组合

### 组合
- 解释器
- 责任链
- 状态
- 命令

### 适合场景
- 协议字段解析复杂
- 需要逐段校验、转换、分发
- 解析过程带上下文状态
- 最终动作要以命令形式提交

### 组合关系
- **解释器**：理解字段 / 规则 / 小语法
- **责任链**：拆成多段处理与校验
- **状态**：记录解析上下文
- **命令**：解析成功后形成可执行请求

## C05 子系统封装组合

### 组合
- 外观
- 适配器
- 代理
- 装饰

### 适合场景
- 对外只想暴露统一入口
- 内部有老模块、第三方模块、复杂初始化
- 想加缓存 / 日志 / 限流 / 权控
- 想控制实际资源访问

### 组合关系
- **外观**：给外部暴露简单接口
- **适配器**：把不统一的内部接口收编
- **代理**：控制访问、缓存、延迟初始化
- **装饰**：无侵入增加统计、日志、检测等附加能力

## C06 树形配置处理组合

### 组合
- 组合
- 迭代器
- 访问者
- 备忘录

### 适合场景
- 配置树 / 设备树 / 菜单树
- 需要遍历、导出、检查、统计
- 节点结构不想因为新操作反复修改
- 需要保存现场并支持恢复

### 组合关系
- **组合**：建立树形结构
- **迭代器**：统一遍历方式
- **访问者**：给树增加新操作
- **备忘录**：保存当前树状态或配置快照

## C07 低 RAM 资源控制组合

### 组合
- 享元
- 代理
- 单例
- 原型

### 适合场景
- 对象很多，公共部分高度重复
- 某些资源必须统一访问
- 大对象不想一次性全部初始化
- 需要从模板快速构造轻量对象

### 组合关系
- **享元**：共享内部状态
- **代理**：按需创建并控制访问
- **单例**：唯一资源管理入口
- **原型**：从模板快速派生实例

<a id="c08"></a>
## C08 分层解耦组合

### 组合
- 桥接
- 适配器
- 外观
- 策略

### 适合场景
- 业务层不应知道驱动实现
- 底层实现将持续演进
- 对外接口希望保持稳定
- 不同运行场景下逻辑策略不同

### 组合关系
- **桥接**：断开抽象与实现绑定
- **适配器**：兼容现有驱动接口
- **外观**：统一服务出口
- **策略**：上层根据环境切换行为
