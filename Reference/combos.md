# 常见模式组合

## 1. 多平台产品架构
推荐组合：
- 抽象工厂
- 工厂方法
- 桥接
- 适配器

适合：
- 多 MCU 支持
- 多板卡适配
- 多驱动族切换

## 2. 复杂初始化与配置管理
推荐组合：
- 生成器
- 模板方法
- 单例
- 原型

适合：
- 初始化步骤多
- 参数组织复杂
- 需要默认模板复制
- 存在唯一资源控制器

- 动态切换处理逻辑

## 4. 协议与规则处理
推荐组合：
- 解释器
- 责任链

## 5. 树形结构与批量操作

- 组合
