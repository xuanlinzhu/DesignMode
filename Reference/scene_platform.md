# 场景：多平台 / 多板卡 / 多驱动族适配

## 这个场景的典型问题
- 同一套业务逻辑要支持不同 MCU
- 同一类设备在不同板卡上实现不同
- 驱动对象经常按“成组”替换
- 上层不希望直接感知底层差异
