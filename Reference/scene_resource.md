# 场景：资源受限 / 延迟加载 / 访问控制 / 共享对象

## 这个场景的典型问题
- RAM 紧张，想减少重复对象
- 某些资源访问必须经过统一控制
- 初始化很重，希望按需加载
- 想在不改原模块的前提下加缓存、日志或统计
