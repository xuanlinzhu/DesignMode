# 常见问题

## 1. 我只想快速找到适合自己项目的问题入口，先看哪里？
建议先看：
- [按嵌入式场景查找](./by_scene.md)

## 2. 我已经知道自己想学创建型 / 结构型 / 行为型，先看哪里？
建议先看：
- [按 GOF 分类查找](./by_category.md)

## 3. 我项目里同时有平台适配、状态机、资源控制，应该怎么选？
建议先看：
- [常见模式组合](./combos.md)
然后再回到单个模式页深入阅读。

## 4. 代码说明在哪里？
导航页会链接到：
- `Code/xx/设计说明.md`

## 5. 讲义在哪里？
导航页会链接到：
- `Source/` 下对应的 `.md` 讲义

## 6. 为什么这些导航页用中文，但文件名是英文？
这样做是为了：
- 页面内容更符合中文读者阅读习惯
- 文件名保持简洁稳定，方便 Git 路径管理和链接维护
