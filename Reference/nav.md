# 导航首页

这里是本仓库的导航入口。你可以按照 **分类**、**嵌入式场景**、或 **模式组合** 三种方式查找资料。

## 从这里开始
- [开始导航](./start.md)
- [按 GOF 分类查找](./by_category.md)
- [按嵌入式场景查找](./by_scene.md)
- [常见模式组合](./combos.md)
- [常见问题](./faq.md)

## 你将会跳转到哪里
这些导航页会继续跳转到以下内容：
- `Source/` 下对应的讲义文件
- `Code/xx/设计说明.md` 下对应的工程实现说明

## 推荐使用方式
- 想系统学习：先看 [按 GOF 分类查找](./by_category.md)
- 想解决实际问题：先看 [按嵌入式场景查找](./by_scene.md)
- 想快速选型：先看 [常见模式组合](./combos.md)
