# 适配器模式示例（嵌入式 → PC 运行场景）

## 场景说明

目标：

> 在 PC 上使用 POSIX `pthread`，
>  运行基于 FreeRTOS API 编写的应用代码。

要求：

- 应用层继续调用 `xTaskCreate`
- 不修改应用代码
- 通过适配器内部调用 `pthread_create`

------

# 一、文件结构

```
project/
│
├── main.c                         # Client（应用层）
├── freertos_api.h                 # Target 接口定义
└── freertos_adapter_posix.c       # Adapter 实现（调用 pthread）
```

------

# 二、角色对应（GOF）

| 角色    | 本示例                   |
| ------- | ------------------------ |
| Client  | main.c 中的任务代码      |
| Target  | xTaskCreate 接口         |
| Adapter | freertos_adapter_posix.c |
| Adaptee | pthread_create           |

------

# 三、Target 接口（freertos_api.h）

定义上层依赖的接口（FreeRTOS 风格）：

```
#ifndef FREERTOS_API_H
#define FREERTOS_API_H

#include <stdint.h>

typedef void (*TaskFunction_t)(void *);
typedef void* TaskHandle_t;

typedef int BaseType_t;

#define pdPASS 1
#define pdFAIL 0

BaseType_t xTaskCreate(TaskFunction_t task,
                       const char *name,
                       uint16_t stackDepth,
                       void *params,
                       uint32_t priority,
                       TaskHandle_t *handle);

#endif
```

说明：

- 这是 **Target**
- 应用层只包含这个头文件
- 不感知 pthread

------

# 四、Adapter 关键数据结构（freertos_adapter_posix.c）

用于桥接 FreeRTOS 任务函数与 pthread 入口函数：

```
typedef struct {
    TaskFunction_t task;
    void *arg;
} task_wrapper_t;
```

作用：

- 保存 FreeRTOS 风格任务函数
- 转换为 pthread 可接受的入口函数格式

------

# 五、Adapter 接口实现框架

```
BaseType_t xTaskCreate(...)
{
    // 1. 分配 pthread_t
    // 2. 构造 task_wrapper_t
    // 3. 调用 pthread_create
    // 4. 返回 pdPASS / pdFAIL
}
```

说明：

- 这是 **Adapter**
- 内部调用 `pthread_create`
- 对外暴露 FreeRTOS 风格 API

------

# 六、Client 示例结构（main.c）

```
#include "freertos_api.h"

void myTask(void *arg)
{
    // 业务代码
}

int main(void)
{
    TaskHandle_t handle;
    xTaskCreate(myTask, "Task1", 1024, NULL, 1, &handle);
}
```

说明：

- Client 只依赖 Target
- 完全不包含 pthread 头文件
- 不知道底层实现

------

# 七、适配关系示意

```
main.c (Client)
        ↓
xTaskCreate (Target)
        ↓
freertos_adapter_posix.c (Adapter)
        ↓
pthread_create (Adaptee)
```

------

# 八、核心模式说明（简洁版）

- **Client 不变**
- **Target 固定**
- **Adapter 内部调用 Adaptee**
- 解决接口不兼容问题
- 典型嵌入式迁移与 PC 仿真场景
