请生成一个 **标准 C（C99）** 的完整可运行示例程序，用于演示 **GOF 组合模式（Composite Pattern）** 在“嵌入式菜单树”中的应用。

要求如下：

1. 使用 **struct + function pointer** 模拟面向对象和多态，不要使用 C++。
2. 设计统一抽象 `MenuComponent`，并体现：
   - Component
   - Composite
   - Leaf
3. 菜单树必须较复杂，至少包含以下结构：

```
Main
├── Device Info
│   ├── Model
│   ├── Serial Number
│   ├── Firmware Version
│   └── Hardware Version
├── Settings
│   ├── Display
│   │   ├── Brightness
│   │   ├── Contrast
│   │   └── Language
│   │        ├── Chinese
│   │        └── English
│   ├── Network
│   │   ├── IP Address
│   │   ├── Subnet Mask
│   │   ├── Gateway
│   │   └── DHCP
│   ├── Power
│   │   ├── Sleep Timeout
│   │   ├── Auto Shutdown
│   │   └── Low Power Mode
│   └── Restore Defaults
├── Diagnostics
│   ├── Sensor Status
│   ├── Memory Test
│   ├── Storage Test
│   ├── Network Ping
│   └── Export Log
├── Control
│   ├── Start Service
│   ├── Stop Service
│   ├── Restart Service
│   └── Emergency Stop
└── About
    ├── License
    └── Build Time
```

1. Leaf 分两类：
   - 信息项：执行时打印固定信息
   - 动作项：执行时打印动作日志
2. Composite 节点支持固定容量子节点数组，使用静态分配，不使用动态内存。
3. 程序启动后自动完成以下演示：
   - 打印完整菜单树
   - 统一执行一个 Composite、一个信息 Leaf、一个动作 Leaf
   - 递归遍历整棵树
   - 启动简单交互式菜单导航
4. 输出风格清晰，适合课堂演示。
5. 代码要包含适量注释，结构清晰。
6. 额外给出简短说明：
   - 哪些部分对应组合模式的 Component / Composite / Leaf / Client
   - 如何编译运行
   - 为什么这是组合模式
