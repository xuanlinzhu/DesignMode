请用 **标准 C** 编写一个完整的示例程序，用于演示“享元模式在嵌入式场景中的应用”。

------

# 一、程序目标

实现两种方式对比：

1. **普通方式**：每个对象保存完整配置（存在大量重复数据）
2. **享元方式**：使用共享配置表 + 索引引用（减少内存占用）

程序需要展示：

- 内存占用对比
- 数据访问方式差异
- 两种方式行为一致

------

# 二、系统模型

定义一个 LED 系统：

- LED 数量：`N = 1000`
- 配置模板数量：`M = 5`

------

## 每个配置包含字段：

```c
uint8_t mode;
uint16_t period_ms;
uint8_t duty;
uint8_t polarity;
uint8_t level;
```

------

## 每个 LED 还包含：

```c
uint8_t runtime_state;
```

------

# 三、实现要求

------

## 1. 普通实现

定义：

```c
typedef struct {
    uint8_t mode;
    uint16_t period_ms;
    uint8_t duty;
    uint8_t polarity;
    uint8_t level;
} LedConfig;

typedef struct {
    LedConfig cfg;
    uint8_t runtime_state;
} LedNormal;
```

要求：

- 创建数组：`LedNormal leds[N]`
- 初始化时：从 5 个模板中拷贝配置（使用 `i % M`）

------

## 2. 享元实现

定义：

```c
typedef struct {
    uint8_t cfg_index;
    uint8_t runtime_state;
} LedFlyweight;
```

定义共享配置池：

```c
const LedConfig config_pool[M];
```

要求：

- 创建数组：`LedFlyweight leds[N]`
- 初始化时：只设置 `cfg_index = i % M`
- 不允许复制配置数据

------

# 四、功能要求

------

## 1. 初始化函数

实现：

- `init_normal_leds()`
- `init_flyweight_leds()`

------

## 2. 行为函数

实现两个函数：

------

### 普通版本：

```c
void run_normal_led(int id);
```

直接访问：

```c
leds[id].cfg.xxx
```

------

### 享元版本：

```c
void run_flyweight_led(int id);
```

必须通过：

```c
config_pool[leds[id].cfg_index]
```

访问配置

------

👉 两种方式输出必须一致

------

## 3. 内存对比函数

输出：

- sizeof(LedConfig)
- sizeof(LedNormal)
- sizeof(LedFlyweight)
- 普通方式总内存
- 享元方式总内存
- 节省字节数
- 节省百分比

------

# 五、严格约束（必须遵守）

------

### 1. 使用静态数组

- 不使用 malloc/free

------

### 2. config_pool 必须是 const

```c
const LedConfig config_pool[M];
```

------

### 3. 使用索引而不是指针

```c
uint8_t cfg_index;
```

------

### 4. 两种实现逻辑必须一致

- 输出数据一致
- 只是存储方式不同

------

### 5. 程序必须可编译运行

- 包含 main()
- 使用 printf 输出结果

------

# 六、输出要求

程序运行后必须打印：

------

## 1. 内存对比

格式类似：

```text
===== Memory Compare =====
...
==========================
```

------

## 2. 示例运行结果

打印前 3 个 LED：

```text
[Normal] id=0 ...
[Normal] id=1 ...
[Normal] id=2 ...

[Flyweight] id=0 ...
[Flyweight] id=1 ...
[Flyweight] id=2 ...
```

------

👉 要求：

> Normal 和 Flyweight 的数值完全一致
