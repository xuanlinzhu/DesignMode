# 1. 设计目标

在嵌入式通信场景中实现 Bridge：

- 抽象维度：**Protocol（协议）**
- 实现维度：**Phy（传输方式）**
- 两者独立扩展
- 通过组合而非继承连接

------

# 2. 扁平化文件目录

```
bridge_demo/
  protocol.h

  phy.h
```

说明：

- `protocol.h` —— 抽象层（Abstraction）
- `protocol_modbus.h` —— 具体协议（RefinedAbstraction）
- `phy.h` —— 实现接口（Implementor）
- `phy_uart.h / phy_tcp.h` —— 具体实现（ConcreteImplementor）
- `app_demo.c` —— 组装关系示例

# 3. 传输接口定义（Implementor）

文件：`phy.h`

```
#pragma once
#include <stddef.h>
#include <stdint.h>

typedef struct phy phy_t;

/* 传输能力抽象 */
typedef struct {
    int (*open)(phy_t *phy);
    int (*close)(phy_t *phy);

    int (*send)(phy_t *phy, const uint8_t *data, size_t len);
    int (*recv)(phy_t *phy, uint8_t *buf, size_t buf_len, size_t *out_len);
} phy_ops_t;

/* 传输对象 */
struct phy {
    const phy_ops_t *ops;
    void *ctx;     /* 具体实现私有数据 */
};
```

设计要点：

- 协议层只依赖 `phy_ops_t`
- 不允许协议直接调用 UART/TCP API

------

# 4. 协议抽象定义（Abstraction）

文件：`protocol.h`

```
#pragma once
#include <stddef.h>
#include <stdint.h>
#include "phy.h"

typedef struct protocol protocol_t;

/* 协议接口 */
typedef struct {
    int (*init)(protocol_t *p);
    int (*tx)(protocol_t *p, const uint8_t *payload, size_t len);
    int (*rx)(protocol_t *p, uint8_t *out, size_t out_len, size_t *out_msg_len);
} protocol_ops_t;

/* 协议对象（桥接点在这里） */
struct protocol {
    const protocol_ops_t *ops;

    phy_t *phy;   /* Bridge：连接传输实现 */
    void  *ctx;   /* 协议私有数据 */
};
```

关键点：

> 桥接发生在 `protocol` 内部持有 `phy`
