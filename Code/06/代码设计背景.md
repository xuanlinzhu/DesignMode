# 智能温控器抽象工厂示例

## 1. 抽象工厂概念

| 角色                            | 定义（GoF）                              | 嵌入式智能温控器例子                                         |
| ------------------------------- | ---------------------------------------- | ------------------------------------------------------------ |
| **AbstractFactory（抽象工厂）** | 定义一组可创建的对象接口，保证对象族一致 | `ThermostatFactory`：声明显示模块、传感器模块、通信模块、执行器模块接口 |
| **ConcreteFactory（具体工厂）** | 实现抽象工厂，绑定到具体产品族           | `DIYFactory` / `StandardFactory` / `ProFactory`：对应不同版本，创建具体模块实例 |
| **AbstractProduct（抽象产品）** | 声明某类对象的接口                       | `Display` / `Sensor` / `Comm` / `Actuator`，定义能力接口（显示、读取温度、通信、控制风扇） |
| **ConcreteProduct（具体产品）** | 实现抽象产品接口，具体实现平台细节       | 三色 LED / 数码管 / LCD，模拟 / 数字 / 高精度温度传感器，按键 / UART / WiFi，固定 / 可调速 / 高性能风扇 |
| **Client（客户端）**            | 使用抽象工厂创建对象并调用接口           | 业务逻辑：读取温度、显示温度、发送数据、控制风扇，不关心模块具体实现 |

------

## 2. 模块对象族对应关系

| 版本     | 显示模块 | 传感器模块           | 通信模块               | 执行器模块                       |
| -------- | -------- | -------------------- | ---------------------- | -------------------------------- |
| Basic    | 三色 LED | 模拟温度传感器       | 按键控制（本地）       | 固定转速风扇                     |
| Standard | 数码管   | 数字温度传感器       | UART 控制（本地/调试） | 可调速风扇（PWM 控制）           |
| Pro      | LCD      | 高精度数字温度传感器 | WiFi 接入智能家居      | 高性能可调速风扇（低噪+PWM控制） |

**说明**：

1. 每个版本对象族完整、互斥，保证初始化期绑定一致性
2. 模块类型一致，但性能或能力递增
3. 客户端只依赖抽象接口，不关心模块具体实现
4. 新版本升级只需切换具体工厂，业务逻辑无需改动

------

## 3. 核心结论

- 抽象工厂适合**产品族/版本对象族管理**，而非单个外设或零散模块
- 对象族内部模块类型一致，能力递增
- 初始化期绑定，保证系统内部模块组合一致
- 客户端只依赖抽象接口，实现业务逻辑与版本实现彻底解耦
