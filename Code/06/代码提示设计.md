## 1️⃣ 项目概述

- 模拟智能温控器三种版本：**Basic / Standard / Pro**

- 使用 **抽象工厂模式**组织对象族（显示模块、传感器模块、通信模块、执行器模块）

- 客户端业务逻辑只依赖抽象接口，通过工厂创建对应版本对象族

- 每个模块在 PC 上可通过文本、动画或日志模拟硬件行为

  **项目目录**
  /thermostat_project
  │
  ├─ /factory                    # 工厂注册和对象族
  │   ├─ AbstractFactory.h       # 抽象工厂接口

  │   ├─ Display.h               # 显示模块抽象接口

## 2️⃣ /factory 文件夹

| 文件              | 职责                                                         | PC 演示提示                                                  |
| ----------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| AbstractFactory.h | 定义抽象工厂接口 + ThermostatModuleSet 结构（Display/Sensor/Comm/Actuator） | 客户端只依赖该接口，调用 `createFactory(version)` 获取对象族 |
| Comm.h            | 通信模块抽象接口                                             | 方法：send()/receive()，PC演示可输出日志或模拟传输           |
| Display.h         | 显示模块抽象接口                                             | 方法：init()/showValue()，PC演示可输出文字或图形             |
| Sensor.h          | 传感器模块抽象接口                                           | 方法：readValue()，PC演示可生成随机或模拟温度值              |
| Actuator.h        | 执行器模块抽象接口                                           | 方法：setSpeed()/turnOn()，PC演示可输出文本、动画            |
| FactoryRegistry.c | 静态注册表 + createFactory(version)                          | 注册所有版本的对象族，保证同一版本的模块成族使用             |

**说明**：所有版本模块的抽象接口统一放在 `/factory` 中，方便客户端调用和 PC 演示模拟。

## 3️⃣ 版本模块实现

### Basic 版本

- /Basic
- 模块：
  - LedDisplay.c/h → 三色 LED 显示
  - AnalogTempSensor.c/h → 模拟温度传感器
  - ButtonControl.c/h → 按键控制（本地）
  - FixedFan.c/h → 固定转速风扇
- BasicFactory.c/h → 提供 `getBasicSet()` 返回对象族结构

### Standard 版本

- /Standard
- 模块：
  - SevenSegDisplay.c/h → 数码管显示
  - DigitalTempSensor.c/h → 数字温度传感器
  - UartComm.c/h → UART 通信
  - PwmFan.c/h → 可调速风扇（PWM）
- StandardFactory.c/h → 提供 `getStandardSet()` 返回对象族结构

### Pro 版本

- /Pro
- 模块：
  - LcdDisplay.c/h → LCD 显示
  - HighPrecTempSensor.c/h → 高精度数字温度传感器
  - WifiComm.c/h → WiFi 接入智能家居
  - HighPerfFan.c/h → 高性能可调速风扇
- ProFactory.c/h → 提供 `getProSet()` 返回对象族结构

**说明**：每个版本模块实现都包含完整对象族，方便静态注册表集中管理。

## 4️⃣ main.c（客户端调用）

- 依赖 `/factory/AbstractFactory.h`
- 通过 `createFactory(version)` 获取 `ThermostatModuleSet`
- 只调用模块抽象接口方法：
  - `display->showValue()`
  - `sensor->readValue()`
  - `comm->send()/receive()`
  - `actuator->setSpeed()/turnOn()`
- 无需知道版本内部实现，适合 PC 演示三种版本差异

## 5️⃣ PC 演示提示

- 使用随机数据或预设值模拟传感器
- 显示模块输出文字、简单字符动画或 GUI
- 通信模块输出日志模拟发送/接收
- 执行器模块输出状态或简单动画表示风扇转动
- 切换版本只需传 `version` 给 `createFactory()`，客户端无需修改

## 6️⃣ 设计模式原则体现

- **开闭原则**：新增版本仅需增加模块实现 + 注册表条目
- **依赖倒置**：客户端仅依赖抽象接口
- **单一职责**：
  - /factory → 抽象接口与对象族创建
  - 各版本文件夹 → 模块实现
- **对象族一致性**：保证同一版本的模块配套使用
- **初始化绑定**：`createFactory(version)` 在程序启动时创建对象族
