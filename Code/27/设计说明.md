## 1. 任务目标（必须满足）

实现一个基于 C 语言的策略模式示例，用于模拟：

> **对 ADC 采样数据进行处理时，可以选择不同滤波算法（策略），并在运行时切换。**

系统必须支持：

- 多种滤波策略
- 统一调用接口
- 动态切换策略
- 同一输入在不同策略下得到不同输出

------

## 2. 核心问题（必须体现）

对于同一组 ADC 输入数据：

```text
100, 102, 101, 250, 103, 102
```

系统可以选择不同处理方式：

- 原始输出（RAW）
- 均值滤波（AVG）
- 限幅滤波（CLAMP）

要求：

- 不同算法实现不同效果
- 外部调用方式保持一致
- 不通过 `if/else` 分支选择算法

------

## 3. 模式目标（必须体现）

本示例必须体现策略模式核心思想：

- 算法被封装为独立对象
- Context 持有策略对象
- Context 对外提供统一接口
- 算法可在运行时替换
- 不修改 Context 即可扩展新算法

------

## 4. 数据定义（必须存在）

------

### 4.1 ADC 输入类型

```c
typedef int adc_value_t;
```

说明：

- 使用整数表示 ADC 值
- 不引入浮点运算（保持嵌入式风格）

------

## 5. 抽象策略接口（必须存在）

必须定义统一滤波策略接口：

```c
typedef struct filter_strategy
{
    int (*process)(struct filter_strategy *self, int input);
} filter_strategy_t;
```

说明：

- `process`：输入一个 ADC 值，输出处理后的结果
- 所有策略必须实现该接口
- 外部只能通过该接口使用策略

------

## 6. Context（必须存在）

必须定义滤波上下文：

```c
typedef struct
{
    filter_strategy_t *strategy;
} filter_context_t;
```

------

## 7. Context接口（必须提供）

```c
void filter_context_init(filter_context_t *ctx, filter_strategy_t *strategy);
void filter_set_strategy(filter_context_t *ctx, filter_strategy_t *strategy);
int filter_process(filter_context_t *ctx, int input);
```

语义要求：

### 7.1 `filter_context_init`

- 初始化上下文
- 设置初始策略

### 7.2 `filter_set_strategy`

- 支持运行时切换策略
- 必须打印切换日志

### 7.3 `filter_process`

- 调用当前策略的 `process`
- 返回处理结果

------

## 8. 必须实现的策略（至少3种）

------

### 8.1 RawStrategy（原始输出策略）

结构：

```c
typedef struct
{
    filter_strategy_t base;
} raw_strategy_t;
```

行为：

- 直接返回输入值
- 不保存历史数据

示例：

```text
input: 100 → output: 100
```

------

### 8.2 AverageStrategy（均值滤波策略）

结构：

```c
#define AVG_WINDOW_SIZE 3

typedef struct
{
    filter_strategy_t base;
    int buffer[AVG_WINDOW_SIZE];
    int index;
    int count;
} average_strategy_t;
```

行为：

- 保存最近 N 个采样值
- 输出平均值
- 前期样本不足时按已有数据计算

示例：

```text
输入: 100,102,101
输出: 100,101,101
```

------

### 8.3 ClampStrategy（限幅滤波策略）

结构：

```c
typedef struct
{
    filter_strategy_t base;
    int last_value;
    int threshold;
    int initialized;
} clamp_strategy_t;
```

行为：

- 若当前值与上次值差值超过 threshold，则限制变化
- 否则正常更新

示例：

```text
last=102, input=250, threshold=20 → output=122
```

------

## 11. 核心设计约束（非常重要）

------

### 11.1 禁止使用 if/else 选择策略

错误示例：

```c
if (mode == RAW) ...
else if (mode == AVG) ...
```

------

### 11.2 禁止在 Context 中写算法逻辑

错误示例：

```c
ctx->process = avg_process;  // 或直接写算法
```

必须通过策略对象调用。

------

### 11.3 禁止把所有策略写在一个函数里

每个策略必须是独立结构和实现。

------

### 11.4 禁止修改 Context 代码来增加新策略

新增策略必须：

- 新增结构
- 新增实现
- 不修改已有 Context

------

## 12. 内存与实现要求

- 不使用动态内存（推荐）
- 所有策略对象可使用静态或栈分配
- 不涉及线程
- 不涉及中断
