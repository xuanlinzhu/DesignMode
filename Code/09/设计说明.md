### **设计目标**

创建一个通用的控件原型框架，可以支持不同类型的控件（如按钮、文本框等）。每个控件的样式将通过一个通用的 `style` 结构来管理，样式可以非常复杂，支持不同控件的个性化设置。

------

### **1. 样式结构（`control_style_t`）**

首先，我们定义一个通用的 **控件样式结构体**，该结构体包含不同控件所需的属性。它将支持多种属性，如背景色、文本颜色、边框、字体、圆角等。

```
typedef struct {
    uint32_t background_color;  // 背景色
    uint32_t border_color;      // 边框颜色
    uint16_t border_width;      // 边框宽度
    uint16_t radius;            // 圆角半径
    uint32_t text_color;        // 文本颜色
    uint8_t font_size;          // 字体大小
    uint32_t padding;           // 内边距
    uint32_t shadow_color;      // 阴影颜色
    uint8_t shadow_size;        // 阴影大小
} control_style_t;
```

- **background_color**: 控件的背景色。
- **border_color**: 边框颜色。
- **border_width**: 边框的宽度。
- **radius**: 圆角半径，用于设置控件的圆角效果。
- **text_color**: 文本颜色。
- **font_size**: 字体大小。
- **padding**: 控件内容的内边距（例如按钮文本与按钮边框之间的距离）。
- **shadow_color** 和 **shadow_size**: 设置控件的阴影效果。

### **2. 控件类型（`control_type_t`）**

为了支持不同类型的控件（如按钮、文本框等），我们使用一个枚举来表示不同的控件类型。

```
typedef enum {
    BUTTON,       // 按钮控件
    TEXTBOX,      // 文本框控件
    LABEL,        // 标签控件
    SLIDER,       // 滑动条控件
    CHECKBOX      // 复选框控件
} control_type_t;
```

### **3. 控件结构（`control_t`）**

每个控件会有一个基础结构，包含类型、样式、文本、回调函数等。这里的 `control_t` 结构体包含控件的所有必要信息，并且包含一个样式结构 `control_style_t` 来指定控件的样式。

```
typedef struct {
    control_type_t type;            // 控件类型（按钮、文本框等）
    control_style_t style;          // 控件样式
    const char *label;              // 控件的文本（如果有）
    void (*callback)(void);         // 控件的回调函数
} control_t;
```

- **type**: 控件的类型，使用枚举 `control_type_t` 来区分不同的控件（如按钮、文本框等）。
- **style**: 控件的样式，使用 `control_style_t` 来定义样式属性。
- **label**: 控件显示的文本（如果是按钮、标签、文本框等）。
- **callback**: 控件的回调函数，用于响应事件（例如按钮点击）。

### **4. 原型模板（`control_template`）**

接下来，我们定义一个 **控制模板**，作为每个控件类型的基础模板，所有控件将基于这个模板进行创建。我们将定义多个控件模板（例如按钮、文本框），并提供默认的样式。

```
const control_t button_template = {
    .type = BUTTON,
    .style = {
        .background_color = 0x007BFF, // 默认蓝色背景
        .border_color = 0x0056b3,     // 边框颜色
        .border_width = 2,            // 边框宽度
        .radius = 5,                  // 圆角半径
        .text_color = 0xFFFFFF,       // 白色文本
        .font_size = 16,              // 字体大小
        .padding = 10,                // 内边距
        .shadow_color = 0x000000,     // 阴影颜色
        .shadow_size = 5,             // 阴影大小
    },
    .label = "Default Button",        // 默认按钮文本
    .callback = NULL                  // 默认回调函数为空
};

const control_t textbox_template = {
    .type = TEXTBOX,
    .style = {
        .background_color = 0xFFFFFF, // 默认白色背景
        .border_color = 0x000000,     // 边框颜色
        .border_width = 1,            // 边框宽度
        .radius = 3,                  // 圆角半径
        .text_color = 0x000000,       // 黑色文本
        .font_size = 14,              // 字体大小
        .padding = 5,                 // 内边距
        .shadow_color = 0xAAAAAA,     // 阴影颜色
        .shadow_size = 3,             // 阴影大小
    },
    .label = "Default Textbox",       // 默认文本框文本
    .callback = NULL                  // 默认回调函数为空
};
```

- `button_template` 和 `textbox_template` 是两个控件类型的原型模板，定义了每种控件的默认样式。
- 控件的文本（如按钮的标签、文本框的内容）和回调函数可以通过修改模板的属性进行定制。

------

### **5. 创建控件的函数（`create_control`）**

使用原型模板创建控件的函数，将根据控件类型复制模板，并修改控件的文本和回调函数。

```
void create_control(control_t *control, const char *label, void (*callback)(void)) {
    // 根据控件类型选择合适的模板进行复制
    if (control->type == BUTTON) {
        *control = button_template;  // 复制按钮模板
    } else if (control->type == TEXTBOX) {
        *control = textbox_template;  // 复制文本框模板
    }

    // 修改控件的标签
    control->label = label;

    // 设置回调函数
    control->callback = callback;
}
```

- 这个函数根据控件类型选择合适的原型模板（如按钮模板、文本框模板等）进行复制，并修改控件的标签文本和回调函数。
