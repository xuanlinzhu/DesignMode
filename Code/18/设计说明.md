## 1. 目标

实现一个 **C11 模块**，用**本地文件模拟 Flash**，并通过**缓存代理**管理配置。

核心要求：

- 业务层 **不能直接访问文件**
- 所有读写必须通过代理
- 读走缓存，写只改缓存
- 显式提交才写文件
- 统一管理状态（init / dirty / valid）

------

## 2. 存储模型

使用一个二进制文件模拟 Flash：

```
"flash_storage.bin"
```

规则：

- 文件只存一个 `AppConfig`
- 文件不存在 / 数据非法 → 使用默认配置
- 文件大小必须等于 `sizeof(AppConfig)`

------

## 3. 数据结构（必须一致）

```
typedef struct
{
    uint32_t version;
    uint8_t device_id;
    uint8_t mode;
    uint16_t sample_interval_ms;
    uint32_t baudrate;
    uint8_t enable_log;
    uint8_t reserved[3];
    uint32_t crc32;
} AppConfig;
```

宏：

```
#define APP_CONFIG_VERSION 0x00010001u
```

------

## 4. 代理状态

```
typedef struct
{
    AppConfig cache;
    int is_initialized;
    int is_cache_valid;
    int is_dirty;
    const char *storage_path;
} FlashConfigProxy;
```

------

## 5. 核心规则

### 初始化

```
Init(proxy, path)
```

执行：

- 从文件读取配置
- 校验：
  - version 正确
  - crc32 正确
- 成功 → 加载到 cache
- 失败 → 加载默认配置 + dirty=1

------

### 读

- 只读 `cache`
- 不允许访问文件
- 未初始化返回错误

------

### 写

- 只修改 `cache`
- 更新后：
  - 重新计算 crc32
  - 设置 dirty=1
- 不允许写文件

------

### 提交（Commit）

- 重新计算 crc32
- 覆盖写入文件（wb）
- 成功 → dirty=0
- 失败 → dirty 保持

------

### 重载（Reload）

- 丢弃 cache
- 从文件重新加载
- 失败 → 默认配置 + dirty=1

------

## 6. 默认配置

```
version = APP_CONFIG_VERSION
device_id = 1
mode = 0
sample_interval_ms = 1000
baudrate = 115200
enable_log = 1
reserved = {0,0,0}
crc32 = 重新计算
```

------

## 7. 接口（必须实现）

### 初始化

```
int FlashConfigProxy_Init(FlashConfigProxy *p, const char *path);
```

------

### 获取 / 设置整体配置

```
int FlashConfigProxy_Get(const FlashConfigProxy *p, AppConfig *out);
int FlashConfigProxy_Set(FlashConfigProxy *p, const AppConfig *in);
```

注意：

- `in->crc32` 必须忽略，内部重新计算

------

### 单字段接口（至少实现2个示例）

```
int FlashConfigProxy_GetDeviceId(const FlashConfigProxy *p, uint8_t *out);
int FlashConfigProxy_SetDeviceId(FlashConfigProxy *p, uint8_t v);
```

------

### 提交 / 重载

```
int FlashConfigProxy_Commit(FlashConfigProxy *p);
int FlashConfigProxy_Reload(FlashConfigProxy *p);
```

------

### 状态查询

```
int FlashConfigProxy_IsDirty(const FlashConfigProxy *p);
```

------

## 8. CRC 规则

- CRC 覆盖 `AppConfig` 除 `crc32` 字段外
- 必须提供函数：

```
uint32_t AppConfig_CalcCrc32(const AppConfig *cfg);
```

必须使用：

- `fwrite`
- `fclose`

模式：

- 读："rb"
- 写："wb"

```
#define FLASH_PROXY_OK 0

```

------

## 11. 必须约束

- 必须使用 C11
- 不允许动态内存（malloc）
- 不允许业务层访问文件
- 不允许读接口访问文件
- 不允许写接口直接落盘
- 必须有 dirty 机制
- 必须有 CRC 校验
- 必须有默认配置恢复
