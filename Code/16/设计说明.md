# 外观模式（Facade）电源管理模拟 

# 1. 目标

生成一个 **C语言项目（PC可运行）**，用于演示：

> **外观模式在CPU电源管理中的应用**

要求：

- 控制台程序
- 无硬件依赖
- 用日志模拟行为
- 清晰体现：**Facade统一入口 + 多子系统协作**

------

## 2. 核心设计

系统模拟 CPU 电源管理，包含 4 种模式：

```c
POWER_MODE_OFF
POWER_MODE_STANDARD
POWER_MODE_PERFORMANCE
POWER_MODE_LOW_POWER
```

------

## 3. 外观接口（唯一对外接口）

```c
void PowerFacade_Init(void);
void PowerFacade_SetMode(PowerMode mode);
void PowerFacade_ShowStatus(void);
void PowerFacade_RunTask(const char* name, int workload);
void PowerFacade_Shutdown(void);
```

👉 **main.c 只能调用这些接口**

------

## 4. 子系统（内部模块）

Facade 内部协调以下模块：

- ClockManager（频率）
- VoltageManager（电压）
- PeripheralManager（外设）
- ThermalManager（风扇）
- SchedulerManager（调度/性能）

👉 子系统只在内部使用，**不对外暴露**

------

## 5. 模式行为（核心逻辑）

### PERFORMANCE（高性能）

- 频率：3200 MHz
- 电压：1.20 V
- 外设：全部开启
- 风扇：高速
- 调度：性能优先

------

### STANDARD（标准）

- 频率：2000 MHz
- 电压：1.00 V
- 外设：必要开启
- 风扇：低速
- 调度：均衡

------

### LOW_POWER（低功耗）

- 频率：800 MHz
- 电压：0.85 V
- 外设：最小开启
- 风扇：低速/关闭
- 调度：省电

------

### OFF（关机）

- 频率：0
- 电压：0
- 外设：关闭
- 风扇：关闭
- 调度：停止

------

## 6. 状态结构（示例）

```c
typedef struct {
    PowerMode mode;
    int freq;
    float voltage;
    int fan;
    const char* policy;
} PowerStatus;
```

------

## 7. 行为要求

### 模式切换

调用：

```c
PowerFacade_SetMode(POWER_MODE_PERFORMANCE);
```

输出：

```text
[Facade] Switch STANDARD -> PERFORMANCE
[Voltage] 1.20V
[Clock] 3200 MHz
[Peripheral] ALL ON
[Thermal] FAN HIGH
[Scheduler] PERFORMANCE
```

------

### 状态显示

```c
PowerFacade_ShowStatus();
```

输出：

```text
Mode: PERFORMANCE
Freq: 3200 MHz
Voltage: 1.20 V
Fan: HIGH
Policy: PERFORMANCE
```

------

### 任务模拟

```c
PowerFacade_RunTask("AI Task", 100);
```

要求：

- PERFORMANCE → 快
- LOW_POWER → 慢
- OFF → 禁止执行

------

## 8. main.c 演示流程

```text
Init
ShowStatus
RunTask

→ PERFORMANCE
RunTask

→ LOW_POWER
RunTask

→ STANDARD
ShowStatus

→ OFF
RunTask (失败)
```
